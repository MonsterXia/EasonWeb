# EasonWeb 界面与空状态规范

修改页面、主题或状态提示时使用本规范。路径均相对仓库根目录；具体数值以共享组件为准，调整公共样式时同步本规范。这里只约束前端表现，不改变 CommonServerAPI 的接口或认证契约。

## 视觉方向

- 延续 Eason Space 的轻量轨道主题：留白、细线轨道、小型星点、圆角图标底板，以及克制的薄边框与阴影。装饰服务于内容，不为每段文字增加徽章、渐变或多层卡片。
- 复用 `src/components/PageHeading.vue` 的页面标题体系；页面内的状态提示从属于页面标题，不另造一套大标题。中英文表达都要清楚、温和，主操作说明具体动作；文案遵循 [国际化约定](i18n.md)。
- 沿用 `src/assets/base.css` 的字体栈与语义颜色变量、`src/assets/main.css` 的公共控件样式，以及 `src/assets/light.css` 的浅色适配。
- 使用 `--color-heading`、`--color-text`、`--muted` 表达文字层级；使用 `--color-background-soft`、`--color-border` 表达表面和边界。文字强调使用 `--accent`；实心主按钮使用 `--button-primary-bg` 与 `--button-primary-text`，不要在新组件中硬编码只适用于某一主题的黑、白或旧版薄荷绿。
- 状态装饰可用 `color-mix()` 从语义颜色派生低透明度边框、底色与阴影。文字、图标与按钮在明暗两种主题下都必须清晰。
- 使用现有 Element Plus SVG 图标；方向箭头也用图标组件。图标隐喻与状态匹配，不用放大的灰色信息圆标或 emoji 代替设计。

## 樱花粉主题

全站默认视觉为樱花粉，保留轻量轨道与星点语言。浅色用暖白与花瓣粉，深色用深梅紫底与柔粉；导航、主按钮、选中态、进度条、用户头像及首页插画保持同一色系。主题选择仍支持跟随系统、浅色与深色，不因配色更新重置用户偏好。

`public/theme.js` 在首屏渲染前应用偏好。“跟随系统”使用浏览器的 `prefers-color-scheme`，监听系统变更，并在页面重新可见、恢复及聚焦时重新同步；手动浅色/深色选择不受系统变化覆盖。浏览器工具栏的 `theme-color` 同步为浅色 `#fff7fa` 或深色 `#160f16`。Pages 为该脚本与 HTML 声明 `Cache-Control: no-cache`；自定义域名的缓存规则可能覆盖脚本响应头，因此 Vite 构建还为主题脚本地址追加内容哈希版本号，避免继续运行旧逻辑。验证时区分宿主应用主题和浏览器实际报告的系统偏好。

偏好键为 `eason-theme`。`public/theme.js` 是唯一启动与持久化入口，暴露 `window.EasonTheme`；组件通过 `src/composables/useTheme.ts` 的 `setTheme()` 调用，监听 `eason-theme-change` 更新状态，卸载时清理监听。保留跨标签 storage 事件（含清空存储）和存储不可用时的当前页切换，不另建页面级主题状态。逻辑回归见 `tests/theme.test.js`。

| 语义变量 | 浅色 | 深色 |
| --- | --- | --- |
| `--accent` / 主操作、链接 | `#ad365e` | `#f3abc5` |
| `--on-accent` / 实心按钮文字 | `#ffffff` | `#301521` |
| `--color-background` / 页面 | `#fff7fa` | `#160f16` |
| `--color-background-soft` / 卡片 | `#ffffff` | `#211821` |
| `--color-background-mute` / 次级表面 | `#f9edf2` | `#30232e` |
| `--color-heading` / 标题 | `#382632` | `#fff1f6` |
| `--color-text` / 正文 | `#654e5c` | `#dec9d4` |
| `--muted` / 次要文字 | `#826575` | `#ba9eae` |
| `--color-border` / 分隔与边界 | `#ead4df` | `#493340` |

- 浅粉用于背景、轨道与装饰；浅色界面的小字强调用深玫瑰粉，实心主按钮与分段选中项用柔粉底 `#edb5c9`、深梅色文字 `#4d2639`，通过独立按钮令牌保持文字清晰，不用浅粉文字叠白底。普通文字与背景的对比度至少 4.5:1。
- 樱花元素使用 `SakuraBlossom.vue` 的五瓣花形，复用于品牌角标、首页标题和轨道卫星；全局背景最多两朵淡花与六片稀疏花瓣（移动端三片）。装饰不挡内容、不截获点击，并设 `aria-hidden`；花瓣只用 transform/opacity 缓慢运动，尊重 `prefers-reduced-motion`。工具页不在数据卡片中重复堆花。
- Element Plus 主色各交互态与全站令牌一致，检查 hover、active、disabled、focus 和 loading；禁用时保留按钮位置与内容。
- 成功保持绿色、警告保持琥珀色、错误保持危险色；稀有度沿用游戏语义色。不要将所有反馈染成粉色，也不要修改游戏头像、鹰角官方黑白品牌图。
- 森空岛图片底板跟随 `--color-background-mute`，不按游戏固定黑底/白底。`overviewAssets.ts` 明确区分单色浅墨、深墨和彩色素材；`OverviewArtwork.vue` 只对单色 UI 图标反色并按主题混合，彩色设施、勋章、地图保留原色，禁止对整组图片统一 invert。检查图片自带的半透明底色在两种主题下是否形成突兀色块。
- 森空岛横幅统一从 `base.css` 的 `--skland-banner-opacity` 与 `--skland-banner-scrim-opacity` 取值，分别控制原图与主题遮罩；具体模块、调参和动画行为见 [森空岛 skill](../../skland-frontend/SKILL.md)，不在通用运行文档重复维护。
- 优先使用语义变量及 `color-mix()`，原有插画可保留成组的明暗色阶；禁止在业务组件重新引入薄荷绿主色。

## 首页动画边界

- `OrbitScene.vue` 用独立的顶部文字、动画舞台、底部文字三行布局；舞台设置容器尺寸和裁剪，轨道按舞台宽高的较小值缩放，任意旋转相位都不得侵入文字区。
- 首页“保持好奇”标签在 `hero-visual` 的独立网格行内排版，不以 absolute / bottom 或负 margin 覆盖坐标文字。保留旋转后的边界与阴影空间。
- 验证 320、390、760、820、1280 像素宽度及中英文；同时检查动画阶段、底部文字、标签与卡片边框，不仅检查初始静止帧。

## 统一空状态组件

复用 `src/components/EmptyState.vue`，不再为这类状态引入默认 `el-result`、`el-empty`，也不通过页面级 CSS 复制一套近似组件。已有独立业务设计（例如计算器的地图推荐占位）保留其布局，不机械替换。

组件接受必填 `title`、`description`，可选 `kind`，以及 `actions` 插槽。组件只负责表现；请求、跳转目标、条件分支及重试由调用页面负责。

| 场景 | kind | 图标 / 色调 | 操作规则 |
| --- | --- | --- | --- |
| 未登录或会话失效 | `login` | User / 主色 | 登录为主操作；注册、刷新状态可为次操作 |
| 尚未绑定账号 | `link` | Connection / 主色 | 明确引导去用户中心绑定 |
| 请求成功但无数据 | `empty`（默认） | FolderOpened / 主色 | 解释无数据及下一步；已有刷新工具栏时不重复堆按钮 |
| 加载失败 | `error` | RefreshRight / 警告色 | 提供重试；需要重新认证时提供账号入口 |

- 不将网络错误伪装成空数据或未登录，也不在加载期间闪现空状态。加载期保留骨架屏。
- 森空岛局部刷新保留角色标题和操作栏，骨架屏仅替换数据区域；触发按钮原位显示加载状态并禁用相关操作。不要将此描述为所有页面已有行为：`userPage.vue` 当前刷新会清空资料并显示骨架，具体见 [路由与认证](routing-auth.md)。
- 有数据时使用正常内容；局部操作失败用就近的错误提示，不用整块空状态遮掉仍可用的数据。
- 标题一句话说明当前状态，说明文字解释原因或下一步。可以有轻微站点语气，但不能让文案掩盖登录、绑定、无数据或失败的真实含义。
- 不显示原始异常栈、内部实现术语或敏感信息。复用业务层错误映射。

### 布局与尺寸基准

以下为当前组件的基准，不要求在调用页面重复设置：

| 项目 | 桌面 | 窄屏（≤ 600px） |
| --- | --- | --- |
| 排列 | 图形在左、文案在右，整体居中 | 纵向排列、文字居中 |
| 最小高度 / 内边距 | 300px / 42px 28px | 320px / 28px 0 |
| 图文间距 | 44px | 18px |
| 图形区域 | 132 × 132px | 112 × 112px |
| 标题 | 23px，650 字重，1.45 行高 | 21px |
| 说明 | 14px，1.8 行高，内容区最多 420px | 13px，说明最多 30em |
| 操作区 | 顶部间距 23px，按钮间距 10px，可换行 | 顶部间距 20px，居中换行 |

图标底板为 76px、24px 圆角，主体图标 32px；外围只有细轨道和少量星点。装饰不承载信息，使用 `aria-hidden="true"`；错误容器使用 `role="alert"`。保留可见键盘焦点和 `prefers-reduced-motion` 支持，空状态装饰无需持续动画。当前 `base.css` 全局取消 outline，以链接 / 按钮 / summary 的下划线及输入边框表达 focus-visible；新增交互需检查实际可见性，不能假设浏览器默认焦点环仍在。

### 操作层级与示例

- 每个状态一个明确的主操作。导航用 `router-link`，重试等页内操作用 `el-button`；不要把按钮嵌套在链接中。
- 当前组件将 `actions` 的首个子元素为链接时设为主色实心链接，其他链接为描边；主操作是按钮时显式使用 `type="primary"`。低优先级刷新可用 `text` 按钮，不依赖颜色表达唯一的操作含义。
- 操作控件最小高度 42px、14px 字号、600 字重、10px 圆角。文案使用“绑定鹰角账号”“前往登录”“重新加载”等具体动作，避免仅用“确定”。
- 保持防重复提交和禁用条件；无角色时禁用签到。刷新成功后应退出空状态并显示实际数据。

```vue
<script setup lang="ts">
import EmptyState from '@/components/EmptyState.vue'
import { ArrowRight } from '@element-plus/icons-vue'
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <EmptyState
    kind="link"
    :title="t('game.skland.linkTitle')"
    :description="t('game.skland.linkDescription')"
  >
    <template #actions>
      <router-link to="/user">{{ t('game.skland.link') }} <ArrowRight /></router-link>
    </template>
  </EmptyState>
</template>
```

## 用户中心与账号管理

- 默认展示紧凑的身份概览、联系方式和一条关联账号状态；不要重复渲染资料表格与账号表格，不常驻绑定、更新登录或解绑表单。
- 关联账号展示品牌标识、已绑定 / 未绑定状态和脱敏手机号，通过一个“管理”入口打开弹窗。已绑定只表示绑定关系存在，不能据此宣称上游会话有效。
- 鹰角账号使用 `src/assets/brands/hypergryph.png` 中的官方标识，来源见同目录 README；保持原始黑底白标，不以通用连接图标、字母或主题色重绘替代品牌。
- 管理弹窗内才展示验证表单和解绑操作；解绑需二次确认，与更新登录的主操作分隔。操作期间防止重复提交，关闭弹窗清空密码与验证码，但不重置发送倒计时。成功后关闭弹窗并刷新状态，失败保留弹窗和就近错误提示。
- 用语义颜色、小型头像、细分隔线和简洁的信息行；手机端信息纵向排列、管理入口可触达。所有文案、辅助标签和确认按钮同步维护中英文。

## 验证

- 改动组件或调用页面后运行 `npm run build`；影响 API 或认证时同时运行 `npm test`。
- 用实际浏览器检查桌面与窄屏、浅色与深色：图标比例、标题层级、说明换行、按钮可读性、焦点状态、无横向溢出。不要只凭构建成功判断设计完成。
- 对相关页面覆盖未登录、未绑定、成功但无数据、加载失败、正常有数据；检查登录/绑定跳转、失败后重试恢复，以及恢复后空状态消失。
- 对照截图检查留白、对齐、颜色和装饰克制度；确认没有默认灰色信息大图标或残留旧组件。控制台无新增应用错误。
- 本地测试响应可用于构造状态，但要标明是测试资料；不能据此宣称真实短信、邮件、绑定或签到服务已验证。不要为了视觉检查触发真实发送或签到。

## 弹窗与主操作

- 所有 `ElDialog` 使用 `CloseBold` 关闭图标。公共样式统一为 24px 图标、44 × 44px 点击区域，并为标题预留 40px 右侧空间；内容区可滚动，头尾固定在视口内。账号提交期间继续隐藏关闭入口，保留原有防重复提交约束。
- 有草稿提交语义的弹窗确认或表单提交使用 `src/components/DialogConfirmButton.vue`：48px 最小高度、全宽胶囊、内描边、右侧等高线纹理和圆形勾号；支持 `disabled`、`loading`、`native-type="submit"` 与多行文案，按深浅主题适配。
- 只将主要确认动作使用此样式。清空使用次级文字按钮，解绑保留危险色及二次确认，账号管理通过 X 关闭，不重复放置仅关闭弹窗的“完成”按钮；发送验证码、页面工具栏、普通取消按钮不套用确认样式。

- 即时生效的天赋弹窗只保留 X 关闭与清除计划操作，不重复提供“完成选择”；摘要为静态展示，仅“编辑天赋”打开编辑器。养成空清单仅显示空状态内的添加入口，已有目标时才显示标题栏添加按钮。单角色不额外显示“签到当前角色”，仅一个可重试失败角色时保留逐条重试，多项失败再显示批量重试。
