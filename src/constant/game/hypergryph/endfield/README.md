# 基质计算器数据

核对日期：**2026-10-04（Asia/Shanghai）**。当前快照覆盖「雪凇幽梦」版本，共 **80 把武器、12 个能量淤积点**。这些是本地常量；构建及用户访问时不会请求外部数据源。

## 来源与范围

- [官方「雪凇幽梦」版本更新说明](https://endfield.hypergryph.com/news/2653)（2026-09-02）：确认寒夜幽影、苦难的尽头、点心时刻及雪松林等已公布内容。官方公告用于核对实装范围，不提供完整的三词条和掉落池。
- [终末地一图流](https://github.com/Arknights-yituliu/ef-frontend-v1/tree/f4fff8e4cf3c00733942cacd5fbb12a07b514e68)：`custom/core/weapons.json` 提供武器星级、类型与基质词条 ID；`custom/core/items.json` 提供国服正式名称；`custom/core/energyAlluviums.json` 提供淤积点掉落池；`i18n/locales/zh-CN-weapons.json` 提供词条与地区中文名。
- [CEP 终末地规划器](https://github.com/cmyyx/cep/tree/286962b95408078ca91c99dece748d74166e74b1)：用 `src/data/weapons.ts` 和 `src/data/dungeons.ts` 交叉核对全部 80 把武器的三词条、12 个淤积点的附加属性与技能池；技能专名来自 `src/generated/i18n/wikiData/zh-CN.json` 的 `weapon|武器ID|skill|技能ID|name`。两个项目可能共享游戏数据来源，因此交叉一致不等于独立的游戏内验证。

[sources.json](sources.json) 记录固定提交、提交日期及下载文件的 SHA-256。采集的是游戏名称、属性及掉落池等事实数据，未引入上游计算器算法或组件。游戏内容权利归鹰角网络及相关权利人；上游项目分别标注 GPL-3.0、AGPL-3.0，复用其程序代码时须另行遵循对应许可。

- 修正不知归、佩科5、O.B.J.迅极、作品：众生、作品：蚀迹等名称，以及逐鳞意、规行矩止、余辉未消等技能专名。
- 武器和地区统一使用基质词条：攻击提升、法术伤害提升、源石技艺提升、终结技充能效率提升。白夜新星旧数据的“原始技艺强度提升”为错字。
- `attribute2: null` 仍表示三星武器无附加属性限制。`weaponMatchesRegion` 直接比较同一套规范词条，显示翻译不参与计算。

## 后续维护

1. 先查看官方版本公告，核对已实装武器与地区；不要仅因解包表出现某条目就假定其已开放。
2. 选定上游提交，以固定 SHA 的 raw URL 下载上述文件。更新本地常量前，逐项比较武器名称、类型、星级、三词条和地区掉落池，不从相似名称推测属性。
3. 基础属性池为五项：敏捷、力量、意志、智识、主能力提升。淤积点使用上游能量点组的词条池；这里不计算不同探索等级的掉落概率或材料收益。
4. 同步维护 `sources.json` 的版本、日期、计数、提交和哈希，以及本说明。新增词条须检查中英文 `src/i18n/games.ts`。
5. 运行 `node --test tests/endfield-materials.test.js`、`npm test` 和 `npm run build`；检查新增武器可选择，添加、去重、删除和地区推荐正常。计数断言对应此快照，下次增补时按核实后的清单更新。
